# Hen & Harvest 🐓

A modern poultry e-commerce website showcasing Philippine native chicken breeds through a clean, user-friendly, and responsive interface.

## Overview

Hen & Harvest provides a digital catalogue of Philippine native chickens, allowing visitors to explore available breeds, view product details, and browse chickens by age category.

## Features

- Browse Philippine native chicken breeds
- View product details, prices, and stock availability
- Search and filter products by age
- Sort products by price
- Admin dashboard for managing chicken listings
- Responsive website design

## Live Website

Visit the deployed website: https://yunieuphoria-oss.github.io/Hen-Harvest/

## Admin Dashboard

To access the Admin Dashboard, add `/admin.html` to the end of the website URL.

The dashboard provides product management features for adding, editing, and deleting chicken listings.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Note

This project is a front-end demonstration. Product data is stored in the browser's Local Storage and is not connected to a shared backend database.
